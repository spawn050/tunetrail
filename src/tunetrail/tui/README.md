# Archived legacy TUI

This Textual interface is retained in place for reference and remains connected to
the legacy entry point. It is not the target interface, and no new TUI features are
planned. The planned replacement is a local React interface backed by a local Python
API (roadmap Phases 4U–4V).

Archiving this directory does not disable its behavior or make its data flows comply
with the redesign. See `docs/phase-4r-data-flow.md` for current limitations. Do not
delete or relocate it without separately considering existing users and entry points.
